Token Radar ranks 198 pre-token protocols from the sealed DefiLlama snapshot (2026-11-14) by implied launch value. The multiple for each category is calibrated from the snapshot's own live-token protocols (median market-cap-to-TVL), so the ranking follows the snapshot's figures, not a hand-picked list. Every row carries a concrete 7-step farm plan, and the static dashboard shows the board, a detail view per protocol with the model breakdown, and the calibration table.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
